# Vendored neutron-elastic data

This directory contains the `kduq/neutron_elastic` and
`test/neutron_elastic` subsets copied without modification from
<https://github.com/beykyle/nucleon-nucleus-data> at commit
`adc8558fe9fcf629af41bc909514f8da63d4f590`.

`UPSTREAM_README.md` is the upstream README from that revision. The JSON
records retain their EXFOR accession numbers, uncertainties, units, and corpus
labels. The upstream repository does not currently declare a root license;
preserve attribution and consult its maintainers before broader redistribution.
