# LROM scattering paper notebooks

This directory collects the paper-facing LROM implementation, notebooks, figure
workflows, and draft results.  The emphasis is reproducibility of the paper
figures rather than a polished installable software release.

## Layout

- `lrom/`: maintained reduced-order scattering implementation used by the
  notebooks and figure scripts.
- `notebooks/N1_simple_case.ipynb`: Daniel Xu's executed one- and
  three-parameter Woods--Saxon demonstration.
- `notebooks/draft_figures/`: the paper-figure development notebooks created
  during the November 2026 sprint.
- `workflows/draft_figures/`: scripts for the LROM manifold/coordinate figures,
  the LROM-versus-ROSE CAT plot, and the stacked global cross-section figure.
- `figures/draft_paper/`: current vector PDF exports and the matching Overleaf
  snippets.
- `figures/design_variants/`: the figure-layout and color-encoding alternatives
  considered before selecting the current design.
- `studies/likelihood_models/`: a deliberately separate diagnostic study of
  experimental/model discrepancy and outliers.  These likelihood choices have
  **not** yet been adopted as the final calibration model.

## Current draft figures

1. `lrom_manifold.pdf`: Woods--Saxon family, wavefunction solution manifold,
   predictor locations, and reduced basis.
2. `lrom_coordinates.pdf`: least-squares coordinate targets compared with the
   learned LROM equations and a Galerkin projection.
3. `rose_lrom_cat_one_column.pdf`: one-column computational-accuracy-versus-time
   comparison for LROM and ROSE; `rose_lrom_cat.pdf` is the wider version.
4. `global_cross_sections.pdf`: representative stacked neutron elastic angular
   distributions with provisional posterior-predictive bands.

The LaTeX blocks in `figures/draft_paper/figures.tex` use placeholder captions
and are intended to be copied into Overleaf and edited with the manuscript.

## Reproducing the self-contained figures

Run commands from `paper-v1` so that the local `lrom` package is imported:

```bash
LROM_FIGURE_ONLY=selected python workflows/draft_figures/figure_design_variants.py
LROM_FIGURE_ONLY=coefficients python workflows/draft_figures/figure_design_variants.py
python workflows/draft_figures/build_rose_paper_cat.py
```

The CAT script uses the committed compact benchmark cache.  Rebuilding that
cache from scratch additionally requires the older ROSE benchmark cache, which
is not duplicated here.

The global cross-section and likelihood-comparison scripts are retained as
provenance for the draft results.  They require the curated-data calibration
payload and posterior arrays generated by the global-calibration workflow.
Those large, transient arrays are intentionally not committed.

## Status and scientific caveats

- The LROM manifold, coordinate, and ROSE benchmark figures are paper-draft
  products based on the maintained implementation.
- The global posterior-predictive bands are useful for drafting the layout, but
  the underlying short posterior run is not yet publication quality.
- The likelihood study shows that the reported point errors alone are too
  restrictive for the curated global data.  The robust Student-t and
  KDUQ-matched discrepancy models are candidates for the next long calibration,
  not final methodological choices.

See `studies/likelihood_models/README.md` for the numerical comparison and the
next recommended checks.
